# BitX Labs

A modern, responsive web application featuring custom 3D background animations and seamless email integration.

---

## 🚀 Demo

Check out the live deployment: **[bitxlabs.vercel.app](https://bitxlabs.vercel.app)**

---

## ✨ Features

- **Interactive 3D Visuals:** Powered by custom 3D background scripts (`bg3d.js`) for an immersive user experience.
- **Responsive Styling:** Built with lightweight CSS for optimal display across mobile, tablet, and desktop viewports.
- **Email Integration:** Configured to handle contact and communication directly through client-side scripting.
- **Fast Deployment:** Optimized for instant edge deployment on Vercel.

---

## 🛠️ Tech Stack

- **HTML5** (33.4%)
- **CSS3** (41.1%)
- **JavaScript** (25.5%)
- **Hosting & Deployment:** Vercel
